# Electricity Easy review

The new 40-question **Review Practice · Easy** is at
`/study/electricity/module-1/practice-2`. It uses the shared multiple-choice
engine and the exact module's searchable study notes. Progress, reset and highest
scores are separate from the existing Medium multiple-choice and Hard one-word
attempts. Existing bank wording, answer keys and storage IDs are unchanged.

## Source wording and answer checks

Twelve prompts retain the wording (including original spelling/capitalization)
of `AMEM 10001 Test 1 Study Aid.docx`. The aid has no completed answer key;
answers use the existing audited bank and condensed notes, rather than treating
the prompt sheet as an answer key.

Study-aid extract lines: **4, 5, 7, 9, 20, 25, 30, 33, 34, 35, 37, 38**.
These cover the two ion changes, current, the six electricity sources, EMF,
four resistance factors, watts, series/parallel constants, voltage drop,
missing tolerance band and parallel resistance.

Twenty-eight prompts retain the wording of the supplied marked 50-question
Canvas practice quiz. Their correct choices retain its marked answers:
**5, 6, 8, 9, 10, 11, 12, 13, 14, 16, 17, 21, 23, 25, 26, 27, 28, 31, 33,
35, 36, 37, 38, 39, 40, 42, 47, 50**.

All 40 prompt strings were compared against the original study-aid extract and
original supplied Canvas results text; all matched exactly. All 28 quiz answer
strings were also compared against the original marked keys and matched exactly.

The four choices are simple, self-contained choices, rather than the existing
bank's more detailed scenarios. No choice refers to shuffled answer letters.
Formula recognition is retained; there are no numerical calculations.
Each question records its source line or original quiz number in the bank.

## Deliberate limits

This is a selected review, not every original prompt. Compound explanation
questions and repeated quiz topics were reduced. Ambiguous original questions
were not silently copied: Q1's broad static-charge wording, Q2's unspecified
zero control, Q7's all-of-the-above choice, Q15's unspecified material geometry,
Q24's blanket DMM-superiority claim, Q48's series-resistance/law wording, and
the aid's ambiguous free-electron/current blank are not included.

Explanations qualify simplified source answers where needed: piezoelectric
voltage, potentiometer/rheostat operating connections, full-scale meter
sensitivity, isolation for ohmmeter use and unchanged conductor geometry.
All new prompts and explanations are searchable via the bank-backed Easy Review
references. Existing condensed topics already define these concepts individually.

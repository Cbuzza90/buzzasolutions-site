# Resistor Band Calculations

Source: the user's `Resistor Colour chart.ppt`, with the original chart image extracted to `public/electricity/resistor-colour-chart.png`. The reference viewer displays that original image directly. Grey and white remain digit colours; their blank multiplier/tolerance cells are not used. Temperature coefficients are brown 100, red 50, orange 15, and yellow 25 ppm/°C.

Each attempt contains 20 unique resistor colour sequences: seven four-band, seven five-band, and six six-band questions, shuffled. Drawings label reading direction and display colour names for accessibility. Significant values use a common preferred-value subset; randomization varies digits, multipliers, tolerances, and the sixth band where applicable.

Four bands use two significant digits. Five and six bands use three. Resistance is the significant number multiplied by the band multiplier. Minimum and maximum are calculated from the tolerance, using integer-scaled percentages to avoid floating-point display artifacts. The sixth band is read directly as a temperature coefficient.

The user explicitly requested numerical answer fields for this test, overriding the general multiple-choice/no-calculations preference. Resistance, tolerance, minimum and maximum are required; six-band questions also require temperature coefficient. All three resistance quantities use ohms (Ω), without a unit selector. Decimal, scientific-notation, and properly grouped thousands input are accepted. Older saved kiloohm/megaohm answers and drafts convert to ohms on restore, preserving scores. The chart viewer displays the original course image with zoom controls. A question earns one point only when all its fields are correct; feedback identifies each field separately.

The custom route is `/study/electricity/module-1/resistor-band-calculations`. It uses the shared browser-storage helpers and Reset Test event. Saves include the exact generated band order, submitted answers, position, unfinished draft and completed state. Restoring reconstructs and regrades from band data. Reset retains the best completed score out of 20. Source version changes should bump the persistence version before changes to interpretation or grading.

Searchable Electricity notes include the full colour mapping, formulas and band roles. Every generated question in the active attempt has a searchable worked reference, also available on results. The course chart opens from both the test and notes; nested closing preserves notes and test progress. Existing multiple-choice Electricity practice is retained separately.

Verification covers the chart's printed examples (22 Ω ±5%, 2,200 Ω ±1%, and 100,000 Ω ±0.1% at 15 ppm/°C), fractional multipliers, blank-cell rejection, valid unique generation, unit conversion, individual field grading, persistence, corruption recovery, reset and nondecreasing best scores. Browser verification completes a full 20-question attempt, checks wrong-field feedback, and checks mobile layouts and nested chart/notes use.

source comparison; active question and note references use the SVG replacements.

These redraws preserve the educational component identities and connections;
decorative shading and photographic details are replaced with clear vector shapes.
The existing actuator-comparison and torque-chart SVGs were already vectors.

The power-pack source sentence says extension while its arrows say Up. That
existing source ambiguity remains documented in the Systems notes. The redraw
keeps the Up arrows and does not assert a gear extension/retraction state.

The resistor chart intentionally excludes the six-band/temperature-coefficient
material, matching the user's requested test scope. Grey and white multiplier
cells stay empty as in the supplied chart. Values are displayed in ohms.
